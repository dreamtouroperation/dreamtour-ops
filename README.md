# Dream Tour Ops

Одна страница на три роли:

- **Турист** вводит код своей группы и видит маршрут по дням, свой пакет и допы, прилёт и машину в аэропорт.
- **Гид** вводит свой код и видит свои машины на день со списком гостей и свои группы.
- **Администратор** открывает `/#admin`: прилёты, вылеты, машины, КАПАК, гиды, группы, загрузка Excel.

## Как устроено

- `public/index.html` — всё приложение.
- `netlify/functions/data.mjs` — `/api/data`: отдаёт и сохраняет данные в Netlify Blobs.
- `public/seed.json` — стартовые данные, пока администратор ничего не опубликовал.

Данные шифруются в браузере: каждая группа своим кодом, каждый гид своим кодом, копия администратора паролем администратора. На сервере лежат только зашифрованные данные.

## Деплой

Netlify → Add new site → Import an existing project → GitHub → `dreamtour-ops`. Настройки сборки не нужны, всё берётся из `netlify.toml`.
